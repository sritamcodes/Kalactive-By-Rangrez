# KALATIVE E-COMMERCE — split files

Place these files in your PHP project:

E-COMMERCE/
├── index.php
├── css/style.css
├── js/script.js
├── videos/Hero-Video.mp4
└── images/logo.png

Run through PHP/Apache (for example XAMPP):
http://localhost/E-COMMERCE/

Do not open index.php by double-clicking it.

The hero video path in index.php is:
videos/Hero-Video.mp4

If you have the logo file, place it at:
images/logo.png
